# API Reference

Base URL: `http://127.0.0.1:8000/api`

GET `/health`
GET `/dashboard`

Events: GET/POST `/events`, GET/PUT/DELETE `/events/{id}`
Resources: GET/POST `/resources`
Allocations: GET/POST `/allocations`
Attendees: GET/POST `/attendees`
Registrations: GET/POST `/registrations`, POST `/registrations/{id}/checkin`
Vendors: GET/POST `/vendors`
Budgets: GET/POST `/budgets`
Expenses: GET/POST `/expenses`
Notifications: GET `/notifications`, POST `/notifications/read-all`
Approvals: GET/POST `/approvals`
Workflows: GET/POST `/workflows`
Reports: GET `/reports`
